
# Sparkl Edventure

## About

Sparkl Edventure builds technology-led learning experiences for students, teachers, and training professionals.

## Platform Highlights

- 📚 **Learning Platforms** — Student, teacher, and training portals
- 🤖 **AI & Tutoring** — AI tutors, content generation, assessments, and analytics
- 📱 **Mobile Applications** — Cross-platform apps built with Flutter
- 🧩 **Microservices** — Scalable backend services across Go, Python, Laravel, Java, and Node.js
- ✅ **Quality & Automation** — QA automation and system testing
- 🎓 **Assessment Products** — JEE/NEET, SAT, IB, and custom assessment systems
